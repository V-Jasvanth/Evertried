# EverTried

EverTried is a platform designed to connect employers with workers for flexible job opportunities.

## Project Progress

### Authentication
- Implemented passwordless email OTP authentication
- Integrated Gmail SMTP using Nodemailer
- Added OTP generation and verification
- Added JWT-based authentication
- Added Google authentication workflow

### Backend
- Connected the application to MongoDB Atlas
- Configured Express server
- Added authentication routes
- Added user and job APIs
- Added dashboard APIs
- Added Socket.IO for real-time communication

### Dashboards
- Worker Dashboard
- Employer Dashboard
- Coordinator Dashboard
- Real-time job application and hiring workflow
- Worker assignment tracking

### Frontend
- React + Vite frontend
- Authentication context
- Protected dashboard workflows
- Digital signature component
- Contract viewer
- Error boundary
- Production build successfully verified

## Current Status

The core authentication, database connection, dashboard workflows, and OTP login system are working in the local development environment.
